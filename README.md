# PrivaNet Admin Panel

This repository is the planning and source home for the PrivaNet Chat Admin / Admin Panel project.

> Important: this project has its own release train. **Chat Admin v0.4.0 is not the same thing as PrivaNet Core v0.4.0.**

Current published Chat Admin release: **v0.3.2**

## Current focus

The project is currently in the **0.3.x stabilization and operator-UX phase**.

The working roadmap for finishing 0.3.x and designing 0.4.0 lives in [ROADMAP.md](./ROADMAP.md).

The roadmap is intentionally marked as **planning**, not fixed scope. It is expected to change while the architecture and product direction are brainstormed before implementation begins.
